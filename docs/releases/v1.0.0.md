# v1.0.0 — CoreS3 USB Spectrum

M5Stack CoreS3をUSBオーディオ入力のスペクトラムアナライザーにする初回リリースです。Windowsの出力先に **CoreS3 USB Spectrum** を選んで使えます。普段の使用に専用PCアプリや追加ドライバーは不要です。

## 主な機能

- USB Audio Class 2.0、48 kHz / 16 bit / ステレオ受信。
- 4096点FFT、32対数バンド、ピーク保持、左右RMS、波形表示。
- 逆位相のステレオ信号でも打ち消されない解析。
- 表示の保持、本体スピーカーのミュート切り替え。
- 内蔵モノラルスピーカーへの再生、入力停止時の待機表示。

## ダウンロードと導入

**`cores3-usb-spectrum-v1.0.0.zip`** に書き込み用BIN、導入手順、ライセンスをまとめています。BIN単体も添付しています。ZIPとBINのSHA-256は `SHA256SUMS.txt` で確認できます。

対象は **CoreS3（16 MB Flash / 8 MB Quad PSRAM）**。Core2用ではありません。元のファームウェアを残す場合は、先にフラッシュ全体をバックアップしてください。

RESETを緑LEDが点灯するまで約3秒長押しして離し、実際のCOM番号を指定して書き込みます（esptool 5.2.0）。結合BINなので書き込み先は **0x0** です。

```powershell
python -m esptool --chip esp32s3 --port COM4 --after watchdog-reset write-flash 0x0 cores3-usb-spectrum-v1.0.0.bin
```

[導入・バックアップ・ビルド手順](https://github.com/Xenoah/cores3-usb-spectrum/blob/v1.0.0/README.md)

## 確認済みの範囲

CoreS3搭載スタックチャンとWindowsで、標準USBオーディオ／シリアルドライバーによる認識、440 Hz・1 kHz・4 kHz・逆位相・無音の受信試験、再起動後のUSB再認識を確認しました。試験中のスピーカーキュー欠落は0バイトです。

[実機テスト結果](https://github.com/Xenoah/cores3-usb-spectrum/blob/v1.0.0/verification/summary.json)

初回はWindowsの音声出力先を選ぶ必要があります。既存のPCスピーカーとの同時出力には別途ルーティングが必要です。macOS / Linux、物理タッチ、スピーカーの聴感、ケーブルの抜き差しは独立した実測を行っていません。スタックチャンの会話・サーボ機能は使用しません。

USB VID/PIDはEspressifのサンプル値（303A:8000）を使用した試作です。コードはMIT、同梱ライブラリーはそれぞれのライセンスに従います。
