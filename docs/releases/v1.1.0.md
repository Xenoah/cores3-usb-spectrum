# v1.1.0 — 表示更新を高速化

CoreS3 USB Spectrumのスペクトラム・波形表示を最適化しました。動くステレオ信号を8秒間入力した実機測定で、スペクトラムは **15.34 → 134.58回/秒（8.77倍）**、波形は **112.14回/秒** になりました。両モードで音声キューの欠落は0バイトでした。

## 変更内容

- ESP32-S3向けESP-DSP Radix-4 FFTと速度優先のビルド設定を採用。
- 変化した画面領域だけを転送し、内部RAMの2つのDMAバッファでコピーとSPI転送を並行実行。
- 波形の転送範囲を前回・今回の振幅に合わせて縮小。
- 固定33ms待ちを廃止。待機中・HOLD中は不要な解析と描画を省略。
- ピーク保持と減衰を経過時間で計算し、更新頻度が変わっても動きを維持。
- 診断情報に解析・描画・転送時間を追加し、LCD RAMの読み戻し検証を追加。

4096点FFT、32バンド、48 kHz / 16 bit / ステレオ入力は維持しています。CPUは240 MHz、LCD SPIは標準の40 MHzです。

## ダウンロードと導入

**`cores3-usb-spectrum-v1.1.0.zip`** に書き込み用BIN、手順、測定結果、ライセンスを同梱しています。BIN単体と `SHA256SUMS.txt` も添付しています。

対象は **M5Stack CoreS3（16 MB Flash / 8 MB Quad PSRAM）**。RESETを緑LEDが点灯するまで約3秒長押しして離し、実際のダウンロードモードのCOM番号を指定します。結合BINの書き込み先は **0x0** です。

```powershell
python -m esptool --chip esp32s3 --port COM4 --after watchdog-reset write-flash 0x0 cores3-usb-spectrum-v1.1.0.bin
```

[導入・バックアップ・ビルド手順](https://github.com/Xenoah/cores3-usb-spectrum/blob/v1.1.0/README.md)

## 検証

周波数、振幅校正、逆位相、無音、HOLD解除後の待機復帰を確認しました。LCD RAM読み戻しはスペクトラム・波形各3回、各76,800画素で不一致0でした（色変換の最大差3/255）。DSPテストと依存関係を含むクリーンビルドも通過しています。

実機測定は `1.1.0-dev` の結果です。正式版は診断用バージョン文字列だけを `1.1.0` に変更して再ビルドし、結合BINとZIPを検証しています。正式版BINを再書き込みした実機試験は行っていません。[測定条件・結果と検証済みBINのSHA-256](https://github.com/Xenoah/cores3-usb-spectrum/blob/v1.1.0/verification/performance.json)

更新回数はLCDへの転送完了数で、液晶パネル自体の走査周波数ではありません。値は入力信号に依存し、静止画面では不要な転送を省くため低下します。

Windows標準USBオーディオドライバーを使用し、通常使用に専用PCアプリは不要です。初回は音声出力先を **CoreS3 USB Spectrum** に選択してください。既存のPCスピーカーとの同時出力には別途ルーティングが必要です。
